# About pull requests

Pull requests let you tell others about changes you've pushed to a branch in a repository.
After opening a pull request, you can discuss and review the potential changes with
collaborators and add follow-up commits before the changes are merged.

## Creating a pull request from a fork

To contribute from a fork, create a branch in your fork, commit your changes, and push
the branch to GitHub. Then open a pull request that compares your fork branch with the
upstream repository's target branch. The pull request page shows the base repository,
base branch, head repository, and compare branch so reviewers can understand where the
changes come from.

## Reviewing changes

Reviewers can comment on lines, request changes, or approve the pull request. Keeping
pull requests focused makes review easier.
